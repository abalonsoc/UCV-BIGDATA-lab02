# BI & Big Data - Laboratorio 02

## Objetivo
Crear un esquema en Databricks Unity Catalog mediante Liquibase
y versionar el cambio con Git.

## Herramientas
- Git
- Liquibase Community
- Databricks Free Edition
- Unity Catalog

## Alcance
El laboratorio termina cuando el esquema aparece correctamente
en Unity Catalog. No se crean tablas ni se cargarán datos.
